# Personal info journey lock + bottom nav label rename

Small carried-over change found uncommitted in the working tree, reviewed and
committed as its own change since it is unrelated to the Knowledge/Dashboard
rework in the same branch.

## Personal info: lock Motherhood Journey after registration

`Mother Type` and `Due Date` are one-time choices made at registration.
Editing them later on the Personal Info page could desync tracking data
(pregnancy week calculations, journey card, timeline) that assumes the
value never changes after signup.

- `personal-info.page.ts`: once `user.motherType` is set, both the
  `motherType` and `dueDate` form controls are disabled after the form is
  populated with saved data. New `isMotherhoodJourneyLocked` getter exposes
  this to the template.
- `personal-info.page.html`: shows a locked-state notice above the
  Motherhood Journey section when `isMotherhoodJourneyLocked` is true,
  explaining the value can't be changed and to contact support if it's
  wrong.
- `personal-info.page.scss`: `.section-note` styling for the notice
  (lavender surface, lock icon, small muted text), matches the app's
  existing card/notice patterns.

## Bottom nav label rename

`tabs.page.html`: renamed 3 of 5 tab labels to shorter, punchier text:
`Knowledge` -> `Learn`, `Chat` -> `Community`, `Tracker` -> `Track`. Icons
and routes unchanged. `Home` and `Profile` labels unchanged.

never get committed.
